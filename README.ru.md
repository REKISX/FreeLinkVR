# FreeLinkVR

[![Read in English](https://img.shields.io/badge/README-English-blue)](README.md)

FreeLinkVR — бесплатный мост между SteamVR на ПК с Windows и телефоном со Steam Link. Проект рассчитан на **телефоны с гироскопом и Steam Link**, включая Android и iOS, и не привязан к определённому производителю.

Клиент Steam Link должен поддерживать рабочую раскладку **«гироскоп → мышь»**. Само наличие гироскопа ещё не гарантирует совместимость. Проверенные устройства и текущие ограничения описаны в [документе о тестировании](assets/docs/testing.md).

- **FreeLinkVR.exe** — лаунчер с кнопками Settings, Setup / Reinstall и Start.
- **FreeLinkVR-Stream.exe** — стереоизображение, повороты головы и дополнительная вкладка библиотеки в SteamVR.
- **driver_freelinkvr.dll** — драйвер виртуального шлема OpenVR.

## Структура проекта

В корне находятся три папки:

```text
FreeLinkVR/
├── src/                     Код, тесты и инструменты разработки
│   ├── FreeLinkVR.sln       Решение Visual Studio без зависимости от CMake
│   ├── FreeLinkVR.props     Общие настройки сборки C++
│   ├── common/              Графика, IPC, математика и форматы файлов
│   ├── platform/            Windows, Steam, установка и настройки
│   ├── launcher/            Лаунчер
│   ├── stream/              Стереопросмотр, ввод и VR-библиотека
│   ├── driver/              Драйвер виртуального шлема
│   ├── tests/               Тесты и диагностические программы
│   └── tools/               Сборка, упаковка и регистрация драйвера
├── assets/                  Ресурсы, документация и зависимости
│   ├── driver/              Манифест и стандартные настройки драйвера
│   ├── steaminput/          Раскладка сенсорного контроллера телефона
│   ├── docs/                Архитектура, тестирование и известные проблемы
│   └── vendor/openvr/       Заголовки OpenVR и их лицензия
├── build/                   Готовые программы и необходимые им файлы
├── CMakeLists.txt
├── README.md
├── README.ru.md
├── LICENSE
├── THIRD_PARTY_NOTICES.md
└── Start.cmd
```

Служебная папка компилятора находится рядом с проектом, например `C:\FreeLinkVR-build`. В ней остаются объектные файлы, кэш, символы отладки, тестовые EXE и снимки тестов. Папка `build/` внутри проекта содержит готовый комплект для запуска.

## Что нужно для работы

- Windows 10 или 11, 64 бита, и видеокарта с Direct3D 11.
- Установленный Steam с выполненным входом в аккаунт.
- SteamVR из Steam. Если он отсутствует, Setup откроет его установку.
- Установленный SteamVR Home: его библиотека Steam API используется для интеграции ввода.
- Телефон с гироскопом, Steam Link и поддержкой раскладки «гироскоп → мышь».
- Для использования в очках — держатель телефона с подходящими линзами.

Steam, SteamVR, Steam Link и их DLL не входят в комплект FreeLinkVR.

## Что именно собирать

Открой **`src/FreeLinkVR.sln`**, выбери **Release | x64** и нажми **Build → Build Solution** — «Сборка → Собрать решение». Для запуска через F5 назначь **FreeLinkVR** запускаемым проектом: правой кнопкой по проекту → **Set as Startup Project**.

| Проект | Назначение | Результат |
| --- | --- | --- |
| **FreeLinkVR** | Основное приложение и упаковка; автоматически собирает свои зависимости | `build/FreeLinkVR.exe` |
| FreeLinkVR-Stream | Стереопросмотр и повороты головы | `build/FreeLinkVR-Stream.exe` |
| driver_freelinkvr | Виртуальный шлем SteamVR | `build/freelinkvr/bin/win64/driver_freelinkvr.dll` |
| freelink_platform | Общая интеграция с Windows и Steam | Внутренняя статическая библиотека вне готового комплекта |

Если нужна только программа, достаточно собрать проект **FreeLinkVR**: он подтянет передатчик, драйвер и библиотеку. Вручную собирать и запускать каждую зависимость не требуется. При сборке всего решения также собираются тесты; дополнительные диагностические проекты для обычного использования не нужны. Скрипт PowerShell дополнительно запускает четыре проверки.

## Сборка

Установи **Visual Studio 2022 или 2026** с компонентом **«Разработка классических приложений на C++»**, инструментами MSVC для x64 и Windows SDK. Для сборки решения Visual Studio CMake и Python не требуются.

### Через Visual Studio

1. Открой **`src/FreeLinkVR.sln`**.
2. Выбери конфигурацию **Release | x64**.
3. Нажми **Build → Build Solution** или **Ctrl+Shift+B**.
4. Запусти `build/FreeLinkVR.exe` либо назначь FreeLinkVR запускаемым проектом и нажми F5.

Также предусмотрена конфигурация Debug | x64. При сборке лаунчера необходимые ресурсы, документация и лицензии копируются в `build/`. В эту папку попадают только два основных EXE; тестовые программы остаются снаружи проекта.

### Через PowerShell

Перед сборкой и тестами закрой FreeLinkVR и SteamVR: интеграционные тесты используют те же имена IPC, что и рабочая программа.

Выполни из корня проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\tools\build.ps1 -Jobs 18
```

Скрипт найдёт MSBuild, соберёт решение в Release и запустит четыре проверки. Для отладочной сборки добавь `-Configuration Debug`. Служебные результаты сохраняются в соседней папке `FreeLinkVR-build/msbuild/`.

Из терминала разработчика Visual Studio можно собрать решение напрямую:

```powershell
msbuild .\src\FreeLinkVR.sln /m:18 /p:Configuration=Release /p:Platform=x64 /p:CL_MPCount=18
```

Эта команда собирает и упаковывает программу, но не запускает тесты. Ранее существовавший проект CMake сохранён как дополнительный способ сборки для Windows. Поддержка Linux не реализована.

Для переноса скопируй или упакуй **всё содержимое `build/`**, включая драйвер, раскладку, документацию и лицензии. После переноса выполни Setup из нового расположения.

## Запуск через лаунчер

1. Открой `build/FreeLinkVR.exe` или `Start.cmd` в корне проекта.
2. Нажми **Setup**. Если SteamVR отсутствует, подтверди его загрузку в Steam и дождись установки. Лаунчер продолжит настройку, когда SteamVR станет доступен.
3. Setup зарегистрирует драйвер, добавит FreeLinkVR в библиотеку Steam и установит раскладку телефона. После успешной настройки кнопка сменится на **Reinstall**.
4. Нажми **Start**, подключись с телефона через Steam Link и выбери FreeLinkVR.
5. Передатчик дождётся телефона и запустит SteamVR. Порядок запуска: **передатчик FreeLinkVR → подключение Steam Link → SteamVR**.
6. Поверни телефон. Если взгляд не меняется, проверь сенсорный контроллер и настройку «гироскоп → мышь» в Steam Link.

Setup и Start могут мягко перезапустить Steam с параметром `-vrdisable`. Он сохраняет обычную передачу окна и удалённый ввод через Steam Link; SteamVR запускается отдельно. Принудительного завершения игр нет. Если Steam не закрывается, заверши игры самостоятельно.

После перемещения комплекта снова выполни **Setup**, чтобы обновить пути драйвера и ярлыка Steam. Держи все файлы из `build/` вместе.

## Запуск без лаунчера

### После первой настройки

Открой Steam, выбери **FreeLinkVR** в библиотеке и нажми **«Играть»**. Можно выбрать тот же ярлык через библиотеку Steam Link на телефоне. `FreeLinkVR-Stream.exe` должен запускаться через Steam, чтобы сохранялись идентификатор ярлыка и раскладка управления.

Если Steam был перезапущен отдельно от FreeLinkVR, запусти его с параметром `-vrdisable`. Перед запуском передатчика закрой самостоятельно запущенный SteamVR: передатчик включит его после подключения телефона.

### Установка и запуск из исходников полностью без лаунчера

Консольный инструмент использует те же функции установки и запуска, что и лаунчер. Это средство разработки, а не третья основная программа.

В терминале разработчика Visual Studio из корня проекта:

```powershell
msbuild .\src\tests\tools\freelink_setup_check.vcxproj /m:18 /p:Configuration=Release /p:Platform=x64 /p:CL_MPCount=18
& ..\FreeLinkVR-build\msbuild\tools\Release\freelink_setup_check.exe --install "$PWD\build"
& ..\FreeLinkVR-build\msbuild\tools\Release\freelink_setup_check.exe --start "$PWD\build"
```

Если установка вернула код **2**, заверши загрузку SteamVR в Steam и повтори `--install`. Для проверки без изменения настройки используй `--status "$PWD\build"`. Перед установкой закрой передатчик и SteamVR.

Только для регистрации драйвера существует `src/tools/register-driver.ps1 -Action register`. Он также поддерживает `status` и `unregister`. Одна регистрация драйвера не создаёт ярлык Steam и не устанавливает раскладку гироскопа.

## Настройки и управление

Настройки сохраняются в `%LOCALAPPDATA%/FreeLinkVR/settings.ini` и применяются при следующем запуске.

| Настройка | Значения |
| --- | --- |
| Разрешение потока | 1280 × 720 или 1920 × 1080 |
| Частота кадров | 30 или 60 FPS |
| Межзрачковое расстояние | 55–75 мм |
| Коррекция линз | Включение и сила 0–60% |
| Чувствительность поворота | 25–200% |
| Просмотр на ПК | Один глаз в формате 16:9, размер 50–100% |
| Полноэкранный режим | Включение и выключение |

По умолчанию: 720p, 60 FPS, 64 мм, коррекция 20%, размер просмотра на ПК 85%. Коррекция применяется отдельно к каждому глазу; подбери её под свои линзы.

| Ввод | Действие |
| --- | --- |
| Касание картинки | Возобновить управление; выбрать пункт под взглядом в библиотеке FreeLinkVR |
| L / Y | Открыть вкладку FreeLinkVR в меню SteamVR |
| Enter / A | Выбрать выделенную игру |
| R / X | Центрировать взгляд |
| M | Переключить захват мыши |
| Esc / B | Приостановить управление и освободить курсор |
| F11 | Переключить полноэкранный режим |
| F8 | Переключить просмотр одного глаза на ПК |
| + / − | Изменить размер просмотра на ПК |
| F2 | Открыть диагностику ввода |

В комплектной раскладке гироскоп включён постоянно: нажимать X для его активации не нужно. Драйвер получает **ориентацию шлема**, а не движение контроллера. Библиотека FreeLinkVR — дополнительная вкладка, она не заменяет стандартные вкладки SteamVR.

## OBS

Добавь источник **«Захват окна»**, выбери **FreeLinkVR - OBS (Mono 16:9)** и метод **Windows 10 (1903 и новее)**. Это отдельный выход одного глаза. Захват игры у процесса передатчика получает стереоизображение.

Просмотр на ПК использует зеркальную текстуру левого глаза SteamVR, когда она доступна, обрезает её до 16:9 и обновляется с частотой до 30 FPS. Масштабирование билинейное с небольшой резкостью, без нейросетевого апскейлера. Увеличение окна не добавляет деталей, которых нет в исходном кадре.

## Текущие ограничения

- **Нерешённый баг:** после сворачивания окна на ПК или ухода из него и возврата Steam Link может остаться с чёрным экраном. До этого перехода стерео работает. Последние попытки восстановления не устранили проблему; разбор отложен. Пока держи окно передатчика открытым во время сеанса.
- Отслеживаются горизонтальный и вертикальный повороты головы. Крена, перемещения головы и отслеживаемых рук или контроллеров пока нет.
- Программного ограничения времени нет, но стабильный двухчасовой сеанс не подтверждён.
- В библиотеке FreeLinkVR могут быть ярлыки игр без VR. Интеграция штатной библиотеки SteamVR с аккаунтом остаётся неполной при `-vrdisable`.
- Job Simulator запускается и отправляет кадры, однако наблюдалась серая сцена. Для полноценной игры также нужны перемещение, откалиброванная зона и отслеживаемые контроллеры.
- Steam Link не предоставляет этому приложению видеопоток камеры телефона.
- На стабильность влияют Wi-Fi, метод захвата Steam и декодер телефона.

Подключения и события окна записываются в `%LOCALAPPDATA%/FreeLinkVR/session.log`; события библиотеки — в `library.log` в той же папке. Диагностика F2 создаёт `input-diagnostics.log` рядом с EXE передатчика.
